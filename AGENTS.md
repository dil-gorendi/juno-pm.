# juno-pm: rules for AI agents

## Language

Each AI tool that works in this repo must obey these rules. Write all text in this repo in ASD-STE100 Simplified Technical English (STE). This rule applies to:

- Each skill file and each prompt.
- Each output that a skill or a prompt makes.
- Each file in the repo, which includes README files and commit messages.

Each skill file must include an STE rule in its Constraints section. This rule makes the model write its output in STE.

Use these STE rules:

- Use active voice.
- Write one instruction in each sentence.
- Use a maximum of 20 words in an instruction and 25 words in a description.
- Use the imperative for instructions.
- Use simple tenses: present, past, and future.
- Use one word for one meaning. Do not use phrasal verbs.
- Use a maximum of 6 sentences in a paragraph.

## Content

This repo is public. Do not put internal company data, customer data, or confidential data in it. Use only the fictional RocketShip scenario of the course.
